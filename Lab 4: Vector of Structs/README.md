# Lab 4: Vector of Structs
[<- Back to Main Repository](../README.md)

## Description
This task revolved using the ideas of vector in order to create a list of struct objects which hold data about the color \
Milestone 1: A struct that can be created and takes in initializing data.
Milestone 2: Create a vector for the `Color` struct objects and random generate between 25-30 `Color` struct object with random init data
Milestone 3: Create a clean input for outputting the objects in the vector

## Creator's Thoughts
- Milestone 1
    - I though that for display that I could have done a cout of each member of the `Color` struct but I though it might be easier to create a function inside of the `Color` struct to do that. Since, that function's only purpose is to display the values of the member.

    - I initially had this display the the vector of `Color` struct by iterating through each `Color` struct in there so I could use the `displayColor` function inside of the `Color` struct, however I removed it since Milestone 3 already is going to do that.

## Description
This lab combines linked list data structures with object-oriented programming to build a movie review system. This task demonstrates how to manage dynamic memory and copy objects safely in C++.

## Creator's Thoughts
- Copy constructors and assignment operators are necessary when using dynamically allocated memory.
- I also didn't know that the vector function automatically calls at least the copy constructor, and I also didn't know that the when I return 0 at the very end, it calls the destructor to remove those.

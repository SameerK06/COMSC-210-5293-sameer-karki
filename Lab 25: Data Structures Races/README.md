# Lab 25: Data Structures Races
[<- Back to Main Repository](../README.md)

## Description
This lab compares the performance of `std::vector`, `std::list`, and `std::set` while reading, sorting, inserting, and deleting string codes. The program measures each operation's runtime in nanoseconds and displays the results in a table.

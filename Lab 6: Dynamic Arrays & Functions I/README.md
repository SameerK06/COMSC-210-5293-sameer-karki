# Lab 6: Dynamic Arrays & Functions I

## Description
This task focused on using dynamic memory allocation to create arrays at runtime and pass them into functions for processing. The program collects a fixed number of `double` values from the user, displays the list, and calculates the total sum through separate helper functions.

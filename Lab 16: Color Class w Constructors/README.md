## Description
This task focuses on the fundamental ideas related to classes within C++ and how they function. Through a simple example of a color class, private and public interfaces are implement as well as independent function to set and assign member values for the class as well as getting those. Furthermore, there will be an implementation of multiple constructor to intake many forms of init for the class.

# Lab 23: Goat Manager 3001
[<- Back to Main Repository](../README.md)

## Description
This lab builds a menu-driven goat manager that lets users add randomly generated goats, remove goats, and display the current goat trip. Goat records are stored in a `std::list`, with goat names, ages, and colors read from the program's data files.

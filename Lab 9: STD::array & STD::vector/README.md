# Lab 9: STD::array & STD::vector
[<- Back to Main Repository](../README.md)

## Description
This task showcases real world usage of `array` and `vector` data structures. Throughout this task, the program must display myriad of function from the `array` and `vector` data structures.

## Creator's Thoughts
 - I wasn't sure about how real world example I could use that won't make this more complex than it needed to be so therefore I chose a thermometer function of recording temperatures.
 - Also I learned about the `.begin()` and `.end()` function with pointer notation.
 - Also I didn't know that you cannot do `double*` in front of the iterator variable for a `for` loop and instead you must do `vector<double>::iterator`.

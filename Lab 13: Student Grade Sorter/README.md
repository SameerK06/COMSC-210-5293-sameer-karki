# Lab 13: Student Grade Sorter
[<- Back to Main Repository](../README.md)

## Description
This lab focuses on reading student records from a file, storing them in a `Student` struct, sorting them by student ID, and writing the sorted data to a new output file. After sorting, the program also calculates summary statistics for the scores, including the minimum, maximum, mean, median, and standard deviation. Many fundamental ideas of the courses are reflected here through the use of `struct`, arrays, file input and output and algorithms as well as statistical analysis.
